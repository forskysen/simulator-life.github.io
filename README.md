# Симулятор жизни V1.1.2

Браузерная игра про жизнь: работа, образование, жильё и машины, бизнесы, майнинг-ферма, биржа, отношения, медицина, банк со счетами и автоплатежом.

## Управление
- **Пробел или Enter** — следующий день
- **← →** — соседняя вкладка, **Shift + ← →** — соседний раздел
- Разделы: Жизнь, Имущество, Финансы, Бизнес, Стата; внутри каждого подвкладки.

## Файлы
- `index.html` — разметка страницы и порядок подключения скриптов
- `style.css` — оформление (тёмная и светлая темы; телефон, планшет, ПК)
- `js/` — вся логика игры, разложенная по темам (`core/`, `features/`, `ui/`, `game/`, `main.js`)
- `DEV_NOTES.md` — карта кода, рецепты «как добавить...» и список изменений
- `tools/` — проверки без браузера: `node tools/smoke-test.js` (быстрая) и `node tools/fuzz-test.js` (случайные клики)

## Запуск
Откройте `index.html` в браузере. Сервер не нужен.
Прогресс сохраняется в localStorage браузера. Сброс и перенос сохранения: кнопка ⚙️ вверху, раздел «Настройки».
Старые сохранения (1.1.1.x) подхватываются автоматически.
Шрифт Onest подгружается с Google Fonts, без интернета подставится системный.
